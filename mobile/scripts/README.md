# mobile/scripts

Helper scripts for the Flutter app build chain. All scripts are idempotent and read secrets from env vars (never hardcoded, never echoed).

## `android-generate-keystore.ps1`

Generates the Play Store upload keystore non-interactively.

```pwsh
# 1. Put the password in 1Password / Bitwarden under "NDT Connect Android Keystore"
# 2. Paste it into the shell as an env var (do NOT commit this line)
$env:NDT_KEYSTORE_PASS = "<paste-here>"

# 3. Run
pwsh ./scripts/android-generate-keystore.ps1
```

Outputs:
- `mobile/android/upload-keystore.jks`
- `mobile/android/key.properties`

Both files MUST be in `mobile/android/.gitignore`. Losing them = losing Play Store update access for this app forever — back the JKS up to 1Password / Codemagic environment.

## Wiring `key.properties` into the Gradle signing config

After `flutter create .` scaffolds `mobile/android/`, edit `mobile/android/app/build.gradle` (or `build.gradle.kts`) and add ABOVE the `android { ... }` block:

```groovy
def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}
```

Then INSIDE `android { ... }` add:

```groovy
signingConfigs {
    release {
        keyAlias keystoreProperties['keyAlias']
        keyPassword keystoreProperties['keyPassword']
        storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
        storePassword keystoreProperties['storePassword']
    }
}
buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled true
        shrinkResources true
    }
}
```

Append to `mobile/android/.gitignore` (auto-generated by `flutter create`):

```
key.properties
*.jks
*.keystore
```

## What's intentionally NOT here

- Mapbox token wiring — passed at build time via `--dart-define=MAPBOX_PUBLIC_TOKEN=...` (Codemagic env vars cover CI; local dev uses your shell).
- iOS signing — handled by Codemagic's App Store Connect integration in `codemagic.yaml`. No local cert/profile management needed.
