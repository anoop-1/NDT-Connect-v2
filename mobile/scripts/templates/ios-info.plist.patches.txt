==============================================================================
MERGE INSTRUCTIONS — mobile/ios/Runner/Info.plist
==============================================================================
After running: flutter create . --platforms=ios --org com.ndtconnect
Flutter generates ios/Runner/Info.plist with a top-level <dict>...</dict>.

Insert each of the key/value blocks below INSIDE that <dict>, before </dict>.

Notes:
 - CFBundleIdentifier in Info.plist is normally set to
   $(PRODUCT_BUNDLE_IDENTIFIER), which is controlled by the Xcode project
   (project.pbxproj -> PBXProject -> PRODUCT_BUNDLE_IDENTIFIER). Set that
   to com.ndtconnect.mobile in Xcode (Runner target -> General -> Bundle
   Identifier) — do NOT hardcode the literal string in Info.plist.
 - The microphone usage description is OPTIONAL — pubspec.yaml currently
   only declares image_picker, not audio recording. Include it ONLY if you
   add an audio package later (record, flutter_sound, etc.). Leaving it in
   without a corresponding capability is harmless but App Store reviewers
   may ask why it is requested.
==============================================================================
