Critical SEO Gaps to Fix

1. No sitemap.xml or robots.txt

Search engines can't efficiently discover and crawl your pages. Atlantis NDT's sitemap lists 366 pages, ensuring every page gets indexed. NDT Connect currently relies entirely on link-based discovery.

2. Only ~15 indexable pages vs 366

NDT Connect has roughly 15 public-facing pages total (home, about, blog x6, find-providers, login, register). Atlantis NDT has 366. This massive content gap means you're invisible for the vast majority of NDT-related searches. Most of NDT Connect's pages (dashboard, admin, settings) are behind auth and not indexable.

3. No geographic landing pages

Atlantis NDT has 100+ city/region-specific pages targeting "NDT consulting Houston", "NDT services Dubai", etc. NDT Connect has zero location-based pages. For a marketplace connecting local providers with clients, this is the single biggest missed opportunity.

4. No dedicated NDT method service pages

Methods like UT, RT, MT, PT each need their own landing page (not just blog posts). These are the core service pages that drive transactional search intent ("book ultrasonic testing", "hire radiographic testing company").

5. Homepage is "use client" - hurts SSR/SEO

The homepage (page.tsx) is a client component that fetches data on mount. The hero content, value propositions, and CTAs are rendered client-side, which can hurt initial crawl-time content. The loading spinner is what Googlebot may see initially.

6. Google verification placeholder

layout.tsx has verification: { google: 'your-google-verification-code' } - this is still a placeholder. Google Search Console isn't connected.

7. Missing OG image and Twitter image

Layout references /og-image.jpg and /twitter-image.jpg but these files don't exist in /public. Social sharing will show broken or generic images.

8. No manifest.json in /public

Layout references /manifest.json but the file doesn't exist. This affects PWA score and certain search features.

9. About page missing metadata export

The /about page has no metadata export - it uses only the root layout metadata. Every public page should have unique title and description.

10. Blog dates are stale (2023-2024)

All blog posts are dated Dec 2023 - Jan 2024. Fresh content signals to search engines that the site is active and current.
