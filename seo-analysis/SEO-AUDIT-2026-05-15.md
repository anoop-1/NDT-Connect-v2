## 🔴 CRITICAL BUG — atlantisndt.com static fallback HTML serves homepage body on every URL

**What I found.** Every page on atlantisndt.com (verified across `/asnt-certification`, `/api-570-certification`, `/api-510-certification`, `/training-me`, `/blog/cwi-certification-...`, `/blog/ndt-salary-guide-2026-global`, `/blog/ultrasonic-testing`) returns the **same static body HTML** to crawlers — homepage content with H1 `"Excellence in NDT Consulting & Training | Atlantis NDT"`. Only `<title>` and `<meta name="description">` are unique per URL.

```html
<!-- /asnt-certification static fallback -->
<h1>Excellence in NDT Consulting & Training | Atlantis NDT</h1>
<h2>NDT Consulting Services</h2>
<p>Atlantis NDT is a global leader in Non-Destructive Testing services...</p>

<!-- /api-570-certification static fallback — IDENTICAL -->
<h1>Excellence in NDT Consulting & Training | Atlantis NDT</h1>
<h2>NDT Consulting Services</h2>
<p>Atlantis NDT is a global leader in Non-Destructive Testing services...</p>
```

**Why it matters.** Googlebot now renders JS, but it indexes the **first-pass HTML** for ranking signals (title, H1, body) and uses the rendered DOM as a secondary refinement. When the static H1/body contradict the title:
1. Google sees a title saying "API 570 Certification" but body content about generic NDT consulting → **topical relevance is diluted**
2. CTR collapses because the cached snippet/preview falls back to the generic body text
3. Pages stall at position 5–15 instead of breaking into the top 3

**Smoking gun in the data:** `/api-570-certification` ranks pos 12 with 3,129 impressions but **0.7% CTR** — pages at position 12 should hit 2-4% CTR on a brand keyword. Same pattern across all 22 high-impression pages.

**Fix.** The site uses Vite (look for `assets/index-*.js`). Either:
- **Recommended:** Migrate to Next.js / React Router SSR (matches the ndt-connect codebase that's already in the repo) — gives proper per-route HTML
- **Quickest:** Add per-route prerendering with `vite-plugin-prerender-spa` or `react-snap`. Generate static HTML for every URL in `sitemap-index.xml` (already exists). This can ship in a day.
- **Stopgap (this week):** Rewrite `index.html` so the static `<noscript>` fallback for each route is route-specific. The repo's `prerender.mjs` (referenced in sitemap as the generator) needs to emit unique H1 + lead paragraph + 2 H2 sections per route.

## ndt-connect.com is built correctly — different problem

`ndt-connect.com/cost-guide/houston/ultrasonic-testing` returns Houston-specific content in the static HTML (Next.js SSG). Title and description are excellent (`"NDT Inspection Cost in Houston (UT): $266-$826/hr 2026"`). But CTR is 0.34% at position 7.

**Diagnosis:** The title leads with **price specificity** (`$266-$826/hr`) for a buyer who's still researching ("ultrasonic testing houston"). At position 7, the snippet is competing with directory results and looks like a calculator more than an inspection provider. Need an A/B titled variant emphasising **service + provider count** ("12 Certified UT Providers in Houston — Free Quotes in 24h").
